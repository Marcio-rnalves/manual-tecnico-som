Mesa de Som

Configurações de alguns detalhes da mesa

  • Verifique o botão de ganho no topo do canal de cada instrumento, o mesmo deve estar ajustado o suficiente para que as luzes que medem o sinal não chegue no máximo, ascendendo a luz vermelha.
  • Verifique se o volume dos canais Auxiliares 2 do microfone sem fio está no máximo. Esse deve estar aberto para gravar a pregação no celular.
  • Use o botão de volume Master para controlar a saída, ajustar conforme necessário durante o Louvor.
  • Evite picos (clip) no medidor de sinal.
